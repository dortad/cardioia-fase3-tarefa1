# Configuração

Esta pasta registrará as versões e configurações usadas na Fase 3, como bibliotecas do ESP32 no Wokwi, parâmetros de conexão com o broker MQTT (sem credenciais) e a versão do Node-RED.

Credenciais nunca devem ser versionadas. Quando necessárias, serão documentadas por um arquivo de exemplo sem valores reais.

O registro de versões da Fase 2 está preservado em [`document/other/fase2/config/`](../document/other/fase2/config/requirements-reproducao.txt).
