# Scripts auxiliares

- `validar_entrega.py`: confere os arquivos obrigatórios e os links locais da documentação da Fase 3. É executado pela integração contínua e também pode ser usado localmente com `python scripts/validar_entrega.py`. Usa somente a biblioteca padrão do Python.

Os acervos em `document/other/` são mantidos como foram entregues e ficam fora dessa verificação.
