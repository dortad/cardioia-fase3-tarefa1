# Parte 2 — Transmissão para nuvem e visualização (Fog/Cloud Computing)

> **Em desenvolvimento.** Esta pasta reservará o código do ESP32 com MQTT e o fluxo do Node-RED.

## Escopo previsto

Conforme a Parte 2 do [enunciado](../../document/Enunciado.md):

- envio dos dados simulados do ESP32 para um broker MQTT;
- dashboard no Node-RED com gráfico de um sinal vital, medidor (gauge) de outro parâmetro e indicador visual de alerta quando os limites definidos pelo grupo forem ultrapassados;
- integração opcional com Grafana Cloud.

## Entregáveis previstos

- código do ESP32;
- prints ou export do dashboard no Node-RED;
- relatório de no mínimo duas páginas sobre o fluxo de comunicação MQTT e a configuração do dashboard.
